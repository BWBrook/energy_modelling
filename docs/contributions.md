# Contributions and provenance

Barry W. Brook wrote the original R model and assembled the recovered input
collection in 2017. In November 2026 he authorised its reconstruction,
complete overhaul and public repository, supplied the recovered files and
provided scientific direction.

OpenAI Codex, identified by this environment as GPT-6, reconstructed the old
execution path, checked its accounting, organised and catalogued inputs,
implemented the Python project, wrote tests and documentation, and integrated
the public repository. Codex delegated bounded data-processing and LP
implementation work, and independent methodological review, to additional
Codex agents. The methodological specialist role is configured as
`gpt-5.6-sol` at high effort; the bounded data executor role is configured as
`gpt-5.6-luna` at high effort. These are the runtime role identifiers supplied
by the environment; exact backend build identifiers are not exposed.

The independent reviewer challenged annualisation, deterministic availability,
emissions-policy scope, storage boundaries and interpretation, then audited
the stable implementation. Testing caught a storage constraint-indexing defect
before handoff. Integration checks corrected missing firm profiles and tightened
the historical calendar and period selection.

The November 7 baseline used the recovered inputs.
The public examples are synthetic. Large recovered data remain outside Git
because their preparation and redistribution provenance are unresolved.
This work-in-progress repository is an engineering and methodological
baseline; it is not a released scientific assessment or a journal submission.

For the eight-by-eight weather experiment, Barry approved the design and
requested the fleet, event and cost comparisons. OpenAI Codex (GPT-6)
implemented and ran the experiment, interpreted the results and wrote the
report. Delegated Codex agents implemented the fixed-fleet replay and
heatmap, and independently reconstructed the results from the recovered
trace and fitted capacities.

For the modern weather replay, Barry requested an out-of-sample test of the
two fixed fleets. OpenAI Codex (GPT-6) selected the AEMO sources, processed
renewable availability, ran the replays and interpreted the results. Delegated
Codex agents extracted the pre-window plant register, reconstructed missing
forecasts from original dispatch cases, processed the demand tables and drew
the worst-day figure. Another Codex agent independently rebuilt the hourly
balances and shortage events from the separate demand and resource files.
